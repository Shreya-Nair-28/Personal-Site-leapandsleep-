#  Leap & Sleep

My personal website: a small space for my
photography, art, projects, and other things I enjoy making.

## What's here?

- Home — a quick introduction
- About — a little about me
- Art & Craft — some of my artwork and DIY projects
- Photography — photographs I've taken
- Contact — places to find me online

## Built with

- HTML
- CSS
- A lot of trial and error

## The idea

I wanted to build my own website instead of using a website builder (I have a website made with wordpress already but I did not have much control over the design),
so this is also a small project to learn and experiment with HTML,
CSS, layouts and GitHub Pages. Initially used ChatGPT but only for the basic HTML structure. Later I went through the guides and external links and figured the format out (took a while indeed). 
I did the rest on my own (the CSS and code for all the pages).
So, I've used very minimal AI.

I did the bg and logo design using Canva. The design does need a little work (especially the colour scheme). I plan to improve that soon. I also hope to add more of my creative works (currently a collection of 3 only).
